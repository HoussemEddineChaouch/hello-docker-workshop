# 🐳 Hello Docker Workshop

A tiny Node.js server built for hands-on practice during the Docker workshop at **Polytechnique Sousse**.

This repository is the starting point for our practical exercises. Every participant can clone the project, run the server locally, and follow along as we learn how to containerize a Node.js application with Docker.

## Workshop Goals

- Understand why Docker exists and which problems it solves.
- Run a simple Node.js application locally.
- Create a `Dockerfile` for our application.
- Build a Docker image and run a container.
- Understand the difference between an image and a container.

## Getting Started

### Prerequisites

Before starting, make sure you have installed:

- [Node.js](https://nodejs.org/) (LTS version)
- [Git](https://git-scm.com/)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — required for the Docker exercises

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/HoussemEddineChaouch/hello-docker-workshop.git
```

### 2. Enter the Project Directory

```bash
cd hello-docker-workshop
```

### 3. Install Dependencies

If the project contains a `package.json`, install its dependencies:

```bash
npm install
```

### 4. Run the Node.js Server

```bash
npm start
```

Follow the instructor's instructions to open the server in your browser.

## 🐳 Docker Workshop

Once the application runs locally, we'll progressively explore how Docker can package and run it in a consistent environment.

We'll work together on:

1. Understanding the application and its environment.
2. Writing a `Dockerfile`.
3. Building a Docker image.
4. Running a container.
5. Testing the application inside the container.

**Don't worry if you haven't used Docker before.** We'll build everything step by step during the workshop.
